# Parmar Properties Listing

Full-stack real estate listing platform consisting of a modern Next.js frontend and a backend service.

## Project Structure

```
Parmar-properties-listing/
├── Frontend/                 # Next.js frontend application
└── backend/
    └── Real-Estate-Listing/  # Backend services and API
```

## Getting Started

### Frontend
```bash
cd Frontend
npm install
npm run dev
```

### Backend
```bash
cd backend/Real-Estate-Listing
npm install
npm run dev
```
